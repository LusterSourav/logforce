1. What we are solving

Firewalls, IDS, switches and apps each log differently. Syslog, JSON, XML, CSV, CEF, LEEF and hand-rolled text arrive together, with different time formats, severity words and multiline traces. Teams today write one parser per device. The parser breaks when firmware updates. SIEM rules drift because the input was never stable.

We need a pipeline that takes any perimeter log, keeps the raw bytes for forensics, normalizes to one schema, and makes it usable for SIEM and ML. It must run air-gapped, inside a container, and not lose data when the downstream stalls.

2. Modular monolith for the prototype

The prototype stays a modular monolith, not microservices: a 2–4 person team, one deployable unit, one docker compose to hand to an evaluator, shared Postgres at this scale. Modules talk only through a public api/ surface, so the classifier can be pulled out to a sidecar later without a rewrite.

ADR-001: extract services only if a module needs independent scaling or a team needs independent deploys. Neither is true today.

3. Hard constraints

Air-gapped, one binary — no model pull at runtime, 23 MB quantized model starts in under 500 ms. Budget is 5 ms per log warm; a batch of many lines is one ONNX call. Raw is never lost: hash the canonical line, keep the full original under unmapped. One regex per new device, not one pipeline rewrite. when_full=block, not drop.

4. Edge engine, briefly

WordPiece to 128 tokens, run ONNX with 3 tensors, mean-pool, project to 1024, cosine against 42 pre-embedded leaves, pick the best above 0.5 or UNCLASSIFIED. Batch packs many texts into one call — that is how 100 lines hit 50–80 ms.

Canonical event from Lumber: type, category, severity, timestamp, summary, confidence, raw. OCSF wraps it with class_uid 4001, integrity hash and the raw event preserved.

Quick start & run

# 1. models are already baked; re-download only if wiped
make download-models

# 2. run the API and open the dashboard
go run ./ui/server.go
open http://localhost:8082/dashboard-v2.html

# 3. try Vector ingestion
export PERIMETER_LOG_PATH=./ingestion/sample.log
vector --config ingestion/vector.toml

# 4. watch NDJSON become Hive
python storage/parquet_writer.py --watch

Folder tour

ui — dashboard and Go API together. One HTML file with mock fallback, real 23 MB ONNX on :8082.

models — quantized ONNX plus vocab and projection weights, hash-pinned for offline bundles.

ingestion — Vector config and VRL. The Phase 1 regex is the only line changed per device.

parsing — SIEM-Lite bridge and 5 hot-swap decoders (Palo Alto, ASA, FortiGate, CEF, Suricata).

storage — Hive writer year/month/day/class/vendor with a 30s watcher.

Verify

curl -s http://localhost:8082/api/health
curl -s -X POST http://localhost:8082/api/classify \
  -H "Content-Type: application/json" \
  -d '{"logs":["ERROR UserService, connection refused"]}'

Air-gapped: models are baked into the image. No model pull at runtime.
