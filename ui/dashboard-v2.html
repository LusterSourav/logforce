How it normalises live

Paste any raw log below. The Go engine tokenizes with WordPiece to 128 tokens, runs the 23 MB quantized ONNX (mdbr-leaf-mt) with 3 tensors (input_ids, attention_mask, token_type_ids), mean pools hidden states, projects to 1024 dim, and cosines against 42 pre embedded leaf texts. Best above 0.5 wins or UNCLASSIFIED. Batch is one ONNX call for 100 lines (50 to 80 ms).

What each log type is for

  • Palo Alto Syslog — firewall traffic, allow/deny perimeter
  • Cisco ASA — Lina data plane, connection build/teardown 5 tuple
  • Fortinet FortiGate — key=value traffic, proto map, action accept
  • CEF / LEEF — ArcSight / QRadar common event, pipe delimited
  • Suricata EVE — IDS alert, event_type alert, signature, severity
  • Zeek TSV — Bro header driven, #fields/#path, OT enrichment
  • ULPF OCSF 4001 — already normalized, fast path, keep raw in GIN
