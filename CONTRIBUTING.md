# Contributing

We want everyone to feel that they can contribute to the LogForce Project.  Whether you have an idea to share, an issue to report, or a pull-request of the finest, most scintillating code ever, we want you to participate!

In the sections below, you'll find some easy way to connect with other LogForce developers as well as some useful informational links on our license and community policies.

Looking forward to building LogForce with you!


## Github

The main project fork lives here in Github:

* [https://github.com/LusterSourav/logforce](https://github.com/LusterSourav/logforce)

If you spot a bug, then please raise an issue in our main GitHub project:

* [https://github.com/LusterSourav/logforce/issues](https://github.com/LusterSourav/logforce/issues)

Likewise, if you have developed a cool new feature or improvement, then send us a pull request! Please read the LogForce developer guide:

* [How to contribute](/docs/introduction/how-tos/how_to_contribute.md)

If you want to brainstorm a potential new feature, hop on over to the Discussions page, listed below.

## Discussions

Sometimes, it's good to hash things out in real time.  We have a Discussions page where you can chat with other LogForce developers and get feedback and support (even if it's just moral support!).

To join the conversation, use this link:

* [https://github.com/LusterSourav/logforce/discussions](https://github.com/LusterSourav/logforce/discussions)
