# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-13

* Initial prototype for perimeter log normalization to OCSF 4001
* Vector plus VRL ingestion with forensic hash and raw preservation
* Go ONNX classifier with 42 leaves and mock fallback
* Hive writer and Postgres GIN for lossless storage
* Dashboard with live ingest counters and health APIs
* Offline bundle with SHA256SUMS and docs
