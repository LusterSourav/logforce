# 500 Internal Server Error — starfield + stick figures

- Status: implemented and verified live (`/500` → 500, panics recovered).
- Scope: `LogForce-Perimeter-Prototype` only.
- Files: `ui/500.html`, `ui/img/stick0-3.svg`, `ui/server.go`
  (`handleServerError`, `withRecovery`), `vercel.json`,
  `docs/500-internal.md`.
- Related: `docs/403-honeypot.md`, `docs/401-unauthorized.md`,
  `docs/404-not-found.md`, `docs/408-timeout.md`.

## 1. What this is

500 means *we* blew up. Two faces: explicit `/500` visits get the page,
and — the real hardening — any panicking handler is caught by
`withRecovery`, logged with a stack trace, and answered 500 instead of
killing the whole process. Before this, one panic took down the server
for every dashboard user. API callers keep JSON errors (the dashboard
parses them); page visitors get the sticks.

## 2. About the animation (two acts)

Act 1 is the starfield + sticks above, with star radius capped at 40px:
uncapped dots fuse into one blob at desktop widths and swallow the white
message (caught by screenshot — the growth math scales with viewport).

Act 2 snaps in the instant Act 1 freezes (`timer >= 500`, ~8s): a white
goo layer holding a wavy black `500` flag, barber pole, `everything is
terrible` caption, and its own nav (it covers Act 1, so it re-provides
the way out). The fade is 0.35s by decision — no drift window. The goo is the blur+contrast force-field trick: 50
overlapping slices reassembling one `500`, each with its own diagonal
`clip-path` and staggered `wave` delay, fused by `blur(5px)` on the wrap
and `contrast(200)` on the parent. The 50 slices are generated by ~10
lines of JS setting `--i`, with `calc()` doing the per-slice position,
clip angle, and phase — same output as a preprocessor loop, no dead
weight. The composition scales via `scale(min(1, 94vw/820))` for phones.
Reduced motion shows the fused flag statically; resize replays the
handoff instead of stranding it half-faded.

- Act 1 source: Ricardo Yare's 500 pen. Kept 1:1: 300-star rush/drift/freeze timeline, all 6 figure flights
  (tops, speeds, spins, parked closer), message hierarchy and copy.
- Fixed: `arc(x, y, r, 0, 360)` → `0, Math.PI*2` (360 radians only works
  by clamping accident); dropped `context.reset()` on resize (missing on
  older browsers; per-frame `setTransform` already resets); SVGs vendored
  to `ui/img/` (source hot-linked GitHub raw — air-gap violation);
  `onerror` hide per figure so one bad file can't leave a broken-image
  icon on stage.
- Restructured, not reinvented: the six copy-pasted `case` blocks became
  one `flyStick(top, bottom, src, duration, spin, tilted)` helper — same
  six flights, ~40 lines fewer.
- Added: rebuild-on-resize (source restarted stars but left figures at
  old coordinates), standard nav row (source stranded the visitor),
  `prefers-reduced-motion` (static message + parked figure, flights
  cancelled; the canvas freezes on its own after ~8s anyway).

## 3. Run and verify

```sh
cd LogForce-Perimeter-Prototype/ui   # go.mod lives here, not the root
STATIC_DIR=. PORT=8081 go run ./server.go
```

Expected:

```sh
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:8081/500          # 500
curl -s http://localhost:8081/500 | grep -c "charactersDiv\|stick"          # 2+
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:8081/             # 200
python3 ../.github/workflows/check_routes.py                                # routes ok: 12 pages checked
```

Open `http://localhost:8081/500`: stars rush for ~1s, drift ~7s, freeze;
figures cross throughout; one stays parked bottom. (Panic path is
verified by code reading + build, not by crashing the live server.)

## 4. Residual risks (accepted)

- Vercel serves the page on `/500` with status 200 (static-rewrite
  limit); Vercel function crashes are Vercel's own 500s, not this page.
- Stack traces go to the server log only, never to the client — keep it
  that way; a 500 page echoing internals would hand busters a map.
